# Cross-Fidelity 自欺审计 · D2 能量对照(打头) + D1/D3

> 论点：**内部一致 ≠ 与现实一致**。一个**通过它全部内部物理预言(EC1–EC5)**的简化数字孪生,
> 仍可能在每次接触**账面能量背离高保真物理现实**——故必须对着现实审计,不能只查内部自洽。
>
> 实现：`g1_pybullet/cross_fidelity.py`(独立 conda env `g1-pybullet`,补 `gymnasium`、**不引 torch/sb3**)。
> 产物：`g1_pybullet/cross_fidelity_energy.json`、`cross_fidelity_energy.png`。
> 🔴 架构红线：PyBullet=物理现实(truth);2D 孪生(`EmbodiedNavEnv`)=被审计的简化模型(其 E_kin 账面=report)。
> 2D 平台**零改动**;master `7b54625` 冻结;无 .pth 改动。**纯新增模块**。

## 0. Setup(Step 0–1)

- **Step 0 env 统一**：`g1-pybullet` 补装 `gymnasium`(无 torch/sb3),令 2D 孪生与 PyBullet 在**同一进程脚本动作双跑**。
- **Step 1 匹配机器人**(`cross_fidelity.py:make_robot`)：PyBullet 圆柱 unicycle,与 2D 孪生**逐项对齐**——
  半径 0.20、质量 1.0、**绕 z 转动惯量 Izz=0.5**(显式覆盖物理盘的 0.02 = 2D `INERTIA_COEF·MASS`)、
  黏性阻尼 `−C_LIN·v / −C_ANG·w`(显式逐子步施加,自带 damping 置零,逐字对齐 2D ODE)。
  时间对齐：2D `DT=0.1` 一个控制步 = **24 PyBullet 子步**(`PB_DT=1/240`)。
- **法向恢复系数标定**(`measure_restitution`)：PyBullet 两体相乘合成 → 取每体 `REST_BODY=√0.5`,
  实测 **有效 e_eff≈0.499 ≈ 2D BOUNCE=0.5**(干净归因:发散来自接触**模型**,非我手设的 e 错配)。
- **平面化**(`_planar_project`)：每子步零化 `vz=wx=wy`(→z/roll/pitch 不漂移)。与 2D 同为平面运动,
  此投影是**匹配**而非 gap。🔴 实测教训：绝不可用 `resetBasePositionAndOrientation`(它清零速度、杀死运动)。

### 匹配等效程度 + 残余差异(诚实)
- **Step 1 自由段验证(无接触)**：直线加速+滑行,2D vs PyBullet——
  **能量 |ΔE| max=0.0143 J(峰值动能 1.10 J 的 ~1.3%)**;**位置差 max=0.023 m**。→ ✅ 干净匹配,**作 FP 本底**。
- **残余差异(明标)**：① 积分格式不同(2D 半隐式 N_SUB=5/h=0.02 vs PyBullet 1/240)→ 自由段 ~0.01 J/0.02 m 本底(已刻画);
  ② 2D 是**非完整 unicycle**(速度恒沿 heading),PyBullet 自由体接触后**可生横向速度**——这一项**正是接触保真 gap 的一部分**(有意,非污染);
  ③ 控制取**直线/前向恒力**,使自由段两侧速度都沿 heading → 规避 unicycle-vs-自由体在转弯时的漂移差(把 gap 收窄到接触)。

**唯一实质 gap = 接触物理**：2D 撞墙模型(`embodied_env.py:706` `v_act*=BOUNCE` 标量速度 ×0.5 + 推出,
**无向量反射/摩擦/接触流形**)vs PyBullet 真接触(向量恢复 + 库仑摩擦 + 接触流形)。

## 1. D2 能量对照(PRIMARY)—— 核心对照

同一恒力控制序列(B-mode `[0.8,0.8]`,稳态 v_ss=1.2 < `V_PHYS_MAX_B`=1.65 → EC3 不误红)同步驱动两侧,
机器人加速后撞墙。**接触时仍施力 → 头对头=压墙、掠射=沿墙持续滑动**。
跨保真能量预言阈 = **5×自由段本底 = 5×0.0143 = 0.0715 J**。

| 场景 | 首接触步 | 接触前 KE | **2D 孪生自检 EC1–EC5** | 自由段 FP 本底 | **接触能量发散** | 跨保真预言 | 末端 E_2d / E_pb |
|---|---|---|---|---|---|---|---|
| head_on (0°) | 19 | 0.715 J | **🟢 全 PASS** | 9.16e-3 J | **0.179 J** | **🔴 FLAG** | 0.032 / **0.000** J |
| glancing_45 (45°) | 25 | 0.719 J | **🟢 全 PASS** | 9.16e-3 J | **0.105 J** | **🔴 FLAG** | 0.032 / 0.081 J |

**🔴 核心对照坐实**：两场景 **2D 孪生都通过它全部内部物理预言 EC1–EC5**(账本 `ΔE=W_act−D_damp−E_contact_decl`
自洽,`energy_audit.py:57`),**却都被跨保真能量预言抓到账面背离 PyBullet 现实**。→ **过全部自检的孪生仍在背离现实**。

### head_on 逐步(最直观:同位置、能量背离)
自由段(step 15–18)两侧能量吻合(|ΔE|~1e-3)、位置同步(x_2d≈x_pb)。接触(step 19,**两者同在 x=1.800 m**):
- **PyBullet 真实 E_pb 立即归零**(撞墙、恒力被法向接触力平衡 → 静止);
- **2D 孪生账面 E_2d=0.179 J → 衰减到残余 0.032 J**:其 `v*=0.5` 模型 + 恒力每步把被砍半的速度**重新注入** →
  孪生"以为"自己仍贴墙**抖动着带动能**。**同一位置(x=1.80m),孪生幻报 0.032–0.18 J 动能,现实是静止(0 J)**。

## 4. emergent vs constructed(明标)

- **emergent(涌现)**：能量/轨迹**发散**由 PyBullet 真接触物理 vs 2D 简化模型**自然产生**——我只设了
  控制序列 + 墙几何 + 摩擦系数,**未手 pin 任何发散状态/故障**。接触本身由"开向墙"涌现。
- **constructed(构造)**：**场景**(开向一面墙)是构造的设置,但其中的**发散是涌现的**(非注入)。
  墙位置/控制是场景 setup,**不是 §7 那种故障注入**。

## 5. 🔴 诚实判断(D2 是否干净 work + complication)

**D2 干净 work**:核心对照成立、FP 本底干净可分离、发散涌现。但有以下 complication,如实报告:

1. **发散的"符号"随几何变**(非单纯"孪生缺摩擦→孪生能量更低")：
   - head_on:孪生**高报**(幻能 0.032 vs 现实 0);glancing:孪生**低报**(0.032 vs 现实 0.081)。
   真实 gap 是**整个粗接触模型**(标量速度砍半 + 钉墙,无向量反射/摩擦),"缺摩擦"只是其一。
   跨保真预言抓 **|发散|**,与符号无关——论点不依赖符号,但"缺摩擦"这一具体措辞**不该单独用**。
2. **发散非单调于入射角**(60° 最大 0.295,45° 最小 0.105):接触动力学随几何非平凡变化。如实呈现,不平滑化。
3. **75° 无接触**(掠射太浅、50 步未达墙):真阴性、非漏检。延长步数可使其接触,本实验保留以示"无接触→不误报"。
4. **接触后两侧轨迹发散**,故接触段能量对照含"账本误差+轨迹差"双重——皆源于同一接触保真 gap;自由段本底已证接触前匹配。
5. **匹配残余**(积分格式、unicycle-vs-自由体)留下 ~0.01 J/0.02 m 自由段本底——已显式刻画并作阈值基线,未掩盖。

**总判**:D2 成立且干净——**简化孪生过全部内部 EC1–EC5,接触处账面能量涌现背离 PyBullet 现实,跨保真预言抓到**。
这正面回击"2D 玩具平台/故障手工注入"批评:故障(背离)由**独立第三方高保真引擎**与简化模型的**真实保真鸿沟**涌现,
非我们设计。**不 over-claim 不可约**(D1 可约、如实标注;不可约证据留在 scenB Table 2)。
