## 0. 攻击与防御
**审稿人攻击**：场景 B（双态耦合）只是「把声称地图给契约层、查上报点 o_t 是否落在墙里」就能抓 →
那样关系型（联合）层就是冗余的，框架的「不可约」主张不成立。

**我们的防御（拓扑不可约）**：真正的关系型故障，连**拿到地图的契约层**也单独抓不出——
因为故障活在**位移向量 o_t − x_t 跨刚性墙**这件事上，而非任一端点落墙里。
需把场景 B 从「o_t 落墙里」（旧形式，确实可约）**重配**为「位移跨墙」（新形式，不可约）来坐实。

**🔴 诚实判据（最重要）**：若在这些条件下带地图契约 baseline **反而抓到了**重配场景 B → 主张可约、需修正，如实报告。
本实验**实测**结果，不为「看起来不可约」调参。

## 1. 重配：从「o_t 落墙」到「位移跨墙」+ 实验参数

**关键前置 d < ξ**：墙厚 d 必须小于传感器噪声预算 ξ，否则无法在噪声预算内把 o_t 放到墙另一侧的自由空间。

| 参数 | 值 | 说明 |
|---|---|---|
| 墙厚 d | **0.20 m** | 薄墙 M = AABB (x∈[30.0,30.2], y∈[9,16]) |
| 噪声预算 ξ | **0.50 m** | 短程(~60 步)诚实漂移 ≈0.2-0.3m（G5 Part D）的 ~2× 余量 |
| **d < ξ** | **0.20 < 0.50 ✅** | 满足关键前置 |
| 真值 x_t | (29.90, y), y∈[10,13] | 墙 **A 侧自由空间**，诚实、从不进墙（运动 L=3m，满足 C1 行程） |
| 报告 o_t | (30.35, y) | 墙 **B 侧自由空间**（**不在墙里**），与真值平行 |
| ‖o_t − x_t‖ | **0.45 ≤ ξ=0.50** | 上报在噪声预算内（含恒定偏置=传感器系统偏差，合法噪声实现） |
| radius | 0（点估计） | task 的 d<ξ 形式；物理半径 R 仅把 d→d+2R，拓扑同构 |

报告 o_t 沿 B 侧自由空间平行于真值上行——其**自身轨迹连续、不穿墙、不落墙**，
唯有**连接 x_t 与 o_t 的位移段**跨越薄墙。

## 2. 五路预言（同一 (truth, odom, M) 上并列）—— 重配场景 B v2

| 预言 | 定义 | 结果 | 说明 |
|---|---|---|---|
| ① 物理 | x_t ∈ 自由空间? (x vs M) | 🟢 **pass** | 真值落墙帧 0/60，合法 |
| ② 契约噪声 | ‖o_t − x_t‖ ≤ ξ? | 🟢 **pass** | max=0.450 ≤ ξ=0.500，上报在噪声内 |
| ③ 🔴 **带地图契约 (M6a)** | o_t ∈ M? (上报点查地图) | 🟢 **pass（漏）** | 上报点落墙帧 **0/60**——o_t 真在自由空间，只是错误一侧 |
| ④ 🔴 **更强 report-only (M6b)** | seg(o_{t-1},o_t) ∩ M? (上报轨迹自穿) | 🟢 **pass（漏）** | 上报轨迹自穿墙段 **0**——B 侧连续路径不自穿 |
| ⑤ **关系型** | seg(x_t,o_t) 穿墙 且端点皆自由? | 🔴 **reject** | 位移段穿墙(端点皆自由) **60/60, frac=1.00** |

**判定 = `IRREDUCIBLE_RELATIONAL`**：①②③④全 pass（含**带地图**契约 M6a/M6b），唯 ⑤ 关系型 reject。
→ 故障只活在 truth↔report 位移段跨墙——**带地图的契约层也分解不出** → **关系型层非冗余、拓扑不可约**。

> 不可约的形式根据：①②③④都是**单端点/单投影**的检查（x 单独、o 单独、‖o−x‖ 单独、o 轨迹单独），
> 而故障 = 「x 与 o 落在被刚性墙隔开的**不同自由连通区**」，是 (x, o, M) 的**三元联合**性质，
> 任何把它分解到单一投影上的检查都无法表达。

## 5. 🔴 诚实代价：d<ξ 让单投影检查在墙附近误报，关系型靠**持续性**保特异性

**d<ξ 是双刃**：它让 o_t 能合法落到墙另一侧（不可约的前提），但同一条件也让**诚实噪声**在薄墙附近偶发跨墙。
30 seed 贴墙健康（真值合法、odom = 真值 + 诚实**无偏**相关噪声 AR(1), clip ‖ε‖≤ξ）实测各预言健康误报：

| 预言 | 健康误报 | 说明 |
|---|---|---|
| ③ 带地图契约 M6a（单点） | **30/30** | 诚实噪声使 o_t 偶尔落进薄墙 → 单点查地图误报（与 G5 Part D「odom 漂入墙」同源）|
| ④ report-only M6b（自穿） | **30/30** | 噪声 odom 在薄墙两侧抖动 → 上报轨迹自穿墙 → 误报 |
| ⑤ 关系型（单帧即判 persist=0） | **25/30** | d<ξ 下诚实噪声偶发位移跨墙 |
| ⑤ 关系型（**持续性门控 persist=0.5**） | **0/30** | 持续性分离后健康零误报 |

**持续性分离（关键）**：故障与噪声的本质区别——
- **场景 B v2**：上报**持续**在错误一侧（恒定偏置）→ 穿墙帧占比 **frac=1.00**；
- **诚实噪声**：上报**无偏**、时均在真值一侧 → 穿墙仅偶发，frac mean=0.10、**max=0.38**。

实测 **健康 frac.max=0.38 < 阈 0.50 < v2 frac=1.00** → ✅ **干净分离**：持续性门控后健康 **0/30** 误报、场景 B v2 **仍抓**。

**结论**：①关系型层对场景 B v2 的**敏感性不可约**（带地图契约结构上抓不到）；②其**特异性**在 d<ξ 墙附近需**持续性门控**
（持续穿墙=真故障 vs 偶发穿墙=噪声）——而这恰是关系型层独有的判别力：**唯它能同时对 v2 敏感、对健康特异**，
任何单投影检查（M6a/M6b）连 v2 都抓不到、且在健康上误报。**所有负/边界结果照报，无一调参强凑。**

> 与 G5 Part D 一致：朴素几何检查在「漂移/噪声 ≳ 墙余隙」时失特异性；部署解法同为**持续性/漂移预算门控**。
